# Azure compute

AZ-104 domain: Deploy and manage Azure compute resources.

## Learn
VM sizes, images, disks, NICs, extensions, availability sets/zones, VM Scale Sets, snapshots, App Service plans/apps/slots/scaling/TLS, Azure Container Registry, Container Instances, Container Apps, ARM and Bicep.

## Labs
1. Deploy a small supported VM only after checking student credit and quota.
2. Inspect size, image, disks, NIC, boot diagnostics and availability.
3. Stop/deallocate the VM; understand which attached resources may still cost money.
4. Explore VM extensions and a safe configuration task.
5. Deploy a low-cost App Service only if the plan is within available allowance.
6. Compare VMs, App Service and container services.
7. Validate the Bicep starter template in this repository.

## Check yourself
- Stop vs Stop (deallocate)?
- Availability set vs availability zone?
- What does an App Service plan define?
- How do deployment slots help releases?
- ARM JSON vs Bicep?

Record what you actually deployed; label documentation-only exercises clearly.
