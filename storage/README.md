# Azure storage

AZ-104 domain: Implement and manage storage.

## Learn
Storage account types and performance; LRS/ZRS/GRS/RA-GRS/GZRS/RA-GZRS; Blob containers, access tiers and lifecycle; Azure Files; account keys, Entra authorization and SAS; firewalls, network rules, private endpoints; soft delete, versioning, snapshots and point-in-time restore; AzCopy and Storage Explorer.

## Labs
1. Create a storage account after checking credit, region and quota.
2. Create a private Blob container and upload synthetic files.
3. Compare Entra authorization, account keys and SAS.
4. Create a short-lived least-privilege SAS for a test object; never commit it.
5. Explore soft delete, versioning and lifecycle management.
6. Create an Azure Files share if supported and affordable.
7. Transfer test data using Storage Explorer or AzCopy.

## Check yourself
- Which redundancy options replicate across regions?
- SAS vs account key?
- Hot/cool/cold/archive tiers?
- What do soft delete and versioning protect against?

Record configuration, verification and cleanup.
