# Identity and governance

AZ-104 domain: Manage Azure identities and governance.

## Learn
- Microsoft Entra ID users, groups, guest users and administrative units.
- Azure RBAC roles, assignments, scopes, inheritance and least privilege.
- Management groups, subscriptions and resource groups.
- Azure Policy definitions, initiatives, assignments and compliance.
- Resource locks, tags, Cost Management, budgets and alerts.

## Labs
1. Inspect tenant, subscription and resource-group boundaries.
2. Create test users/groups only where permitted.
3. Assign Reader to a test identity at resource-group scope; verify access.
4. Compare Owner, Contributor and Reader; inspect inherited role assignments.
5. Apply tags and a safe CanNotDelete lock to a disposable resource.
6. Explore a built-in Azure Policy at lab scope; inspect compliance.
7. Explain why a budget alert is not a hard spending cap.

## Check yourself
- Azure RBAC scopes? How does inheritance work?
- Azure RBAC vs Entra directory roles?
- Policy vs resource lock?
- What do deny effects and exemptions do?

Record the date, configuration, verification evidence (redacted), outcome and cleanup for every lab.
